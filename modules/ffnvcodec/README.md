# ffnvcodec versions

The module name matches the upstream pkg-config package and `ffnvcodec/` include path.

This module includes the latest tag for each distinct minimum driver requirement
declared in the tagged READMEs of the
[official FFmpeg nv-codec-headers repository](https://code.ffmpeg.org/FFmpeg/nv-codec-headers)
across the 11, 12, and 13 release series.
