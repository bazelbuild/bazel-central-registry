# gawk

Generated by the converter of
[`rules_cc_autoconf`](https://periareon.github.io/rules_cc_autoconf/convert.html).
`decisions.bzl` and the `BUILD.bazel` files are hand-maintained; the generated
`autoconf.bzl` beside each is not.

## Updating

Copy the newest version directory, add it to `metadata.json`, update
`source.json` for a new release, then from a `rules_cc_autoconf` checkout:

```shell
bazel run //tools/convert -- convert --bcr-entry <registry>/modules/gawk/<version>
```

Answer any new keys in `decisions.bzl` and rerun; rerun after every edit under
`overlay/`, since it writes the hashes in `source.json`. The bison, gmp and mpfr pins follow the newest versions in the checkout; cut gawk after them. `gawk_tool.bzl`, `gawk_minimal.bzl`, `test/` and the `extension/*_shared` libraries are the plugin support.
