# mpfr

Generated by the converter of
[`rules_cc_autoconf`](https://periareon.github.io/rules_cc_autoconf/convert.html).
`decisions.bzl` and `overlay/BUILD.bazel` are hand-maintained; the generated
`overlay/autoconf.bzl` beside it is not.

## Updating

Copy the newest version directory, add it to `metadata.json`, update
`source.json` for a new release, then from a `rules_cc_autoconf` checkout:

```shell
bazel run //tools/convert -- convert --bcr-entry <registry>/modules/mpfr/<version>
```

Answer any new keys in `decisions.bzl` and rerun; rerun after every edit under
`overlay/`, since it writes the hashes in `source.json`. The platform answers to configure's runtime probes (floating-point formats, limb widths) are the `probe:` and `guard:` decisions; the gmp pin follows the newest version in the checkout.
