# kmod

Generated by the converter of
[`rules_cc_autoconf`](https://periareon.github.io/rules_cc_autoconf/convert.html).
`decisions.bzl`, `overlay/BUILD.bazel` and `overlay/tests/` are
hand-maintained; the generated `overlay/autoconf.bzl` is not.

## Layout

`//:kmod` and `//:libkmod` are the library, `//:libkmod/kmod_shared` its
shared build with `libkmod.sym` as the exported ABI, `//:bin` the multi-call
binary, and `//:modprobe`, `//:depmod`, `//:modinfo`, `//:insmod`,
`//:rmmod`, `//:lsmod` the symlinks the binary tells its commands apart by.
`--@kmod//:module_directory` and `--@kmod//:distconfdir` are configure's
`--with-module-directory` and `--with-distconfdir`; `SYSCONFDIR` is fixed at
the converter's `/usr/local/etc` until it grows a flag.

## Updating

Copy the newest version directory, add it to `metadata.json`, update
`source.json` for a new release, then from a `rules_cc_autoconf` checkout:

```shell
bazel run //tools/convert -- convert --bcr-entry <registry>/modules/kmod/<version>
```

Answer any new keys in `decisions.bzl` and rerun; rerun after every edit under
`overlay/`, since it writes the hashes in `source.json`.
