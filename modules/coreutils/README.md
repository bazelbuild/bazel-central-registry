# coreutils

Generated by the converter of
[`rules_cc_autoconf`](https://periareon.github.io/rules_cc_autoconf/convert.html).
`decisions.bzl`, `overlay/BUILD.bazel` and `overlay/src/version.c.in` are
hand-maintained; the generated `overlay/autoconf.bzl` is not.

Every program `./configure && make` builds on Linux and macOS is a `cc_binary`
under its own name (`@coreutils//:sort`, `@coreutils//:ls`, ...), with the
gnulib library as `@coreutils//:lib/coreutils`.  Left out on purpose: the
single multi-call `coreutils` binary, `stdbuf` (it needs an `LD_PRELOAD`
shared library), the SELinux pair `chcon` and `runcon`, and the OpenSSL and
libcap optional dependencies; the checksum programs use gnulib's digests.

## Updating

Copy the newest version directory, add it to `metadata.json`, update
`source.json` for a new release, then from a `rules_cc_autoconf` checkout:

```shell
bazel run //tools/convert -- convert --bcr-entry <registry>/modules/coreutils/<version>
```

Answer any new keys in `decisions.bzl` and rerun; rerun after every edit under
`overlay/`, since it writes the hashes in `source.json`.
